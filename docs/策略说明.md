# 主流币量化策略说明

## 一、当前范围

策略执行层仅允许交易固定主流币：

```text
WETH, WBTC, AAVE, LINK, UNI
```

所有 DEX 小币直接交易、小币资金流、小币价格动量、聪明钱跟单、清算反转、
CEX-DEX 小币价差、交易所小币净流和“小币信号 → 主流币门控”模型均已退役。
PEPE 不属于默认主流币宇宙。

历史 `reports/strategy/` 和数据库中的旧 run 为审计记录，不代表当前可运行策略。
依赖旧 `inflow_raw + outflow_raw` VWAP 的历史结果全部失效。

## 二、保留策略

### ts-momentum

- 使用 Binance 现货小时价格。
- 最近 lookback 窗口均价高于前一等长窗口才持有。
- 按正动量排序选择前 top-k。
- 是其他模型必须比较的价格基准。

### taker-pressure

- 使用 Binance K 线的 quote volume 和 taker-buy quote volume。
- 主动买入占比大于 50% 才产生信号。
- 仅在固定主流币宇宙内排序。

### funding-reversal

- 使用 Binance USDT-M 永续资金费率。
- 近窗口平均费率为负才入选。
- 交易价格仍使用 Binance 现货小时价格。

## 三、统一成交规则

```text
H 小时完成
  → 使用 <= H 的数据产生信号或退出条件
  → 订单进入持久化 pending 表
  → H+1 小时 Binance close 成交
```

- 入场、止盈、止损和持仓到期全部下一小时执行。
- 持仓到期但仍被策略选中时续持，避免无意义卖出再买入。
- 缺少精确小时价格时回测直接失败，不按旧价或入场价虚构成交。
- 每边默认收取 10bps CEX 费用。
- 回放结束的强制清仓会重新计算最终净值和最大回撤。
- live 重启会恢复现金、持仓和 pending orders。

## 四、资金流数据口径

`token_flow_hourly` 同时保存：

- `inflow_raw/outflow_raw`：全部 swap 原始数量，仅供交易活动统计。
- `priced_inflow_raw/priced_outflow_raw`：只有能够计算 USD 的 swap 数量。

任何 VWAP 或持仓标记只能使用：

```text
(inflow_usd + outflow_usd)
/
(priced_inflow_raw + priced_outflow_raw)
```

升级后必须执行全历史回放：

```bash
node --env-file=.env quant/collectors/collect-token-flows.js --rebuild \
  --start-iso 2024-01-01T00:00:00Z
```

DDL 只新增字段，不在同一事务内回填数百万历史行，以免长期锁表。所有迁移前的
`priced_*` 值会保持 0，直到上述重建逐小时覆盖。重建完成前，地址分析和历史
DEX VWAP 不应作为正式结果。

## 五、回测命令

单策略：

```bash
npm run strategy -- --strategy ts-momentum \
  --from 2024-07-01T00:00:00Z --to 2025-07-01T00:00:00Z
```

同窗口矩阵：

```bash
npm run strategy-matrix -- \
  --from 2024-07-01T00:00:00Z --to 2025-07-01T00:00:00Z \
  --tag majors_matrix
```

矩阵按 Sharpe、总收益和回撤排序，但仍属于样本内比较。

滚动样本外：

```bash
npm run strategy-walk-forward -- \
  --from 2024-07-01T00:00:00Z --to 2026-07-01T00:00:00Z \
  --train-days 180 --test-days 30 --step-days 30 \
  --tag majors_walk_forward
```

walk-forward 每个训练窗选择 Sharpe 最高且交易数达标的策略，只把下一测试窗
收益计入最终结果。是否进入纸面实盘应以 walk-forward 和随后 live 前向结果为准。

## 六、报告指标

每个 run 至少报告：

- 总收益和最大回撤；
- 小时收益年化 Sharpe；
- 平均资金暴露；
- 买入换手率；
- 最大盈利交易占全部正收益的比例；
- 交易数和胜率。

单一交易或单一资产贡献过高时，即使总收益很好，也不能判断为稳定策略。
